# Zentrola

**Open-source AI Coding Control Plane for engineering teams.**

Zentrola connects AI coding clients with an organization's model subscriptions, giving
teams centralized control over providers, credentials, logical models, access policies,
usage, and costs.

## Projects

### [Zentrola](https://github.com/zentrola/zentrola)

The core control plane and gateway. Use it to manage AI providers and credentials,
publish governed models to engineering teams, and audit usage through one platform.
